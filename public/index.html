System & Features

The Frictionless File & Text Drop

High-speed, ephemeral, zero-knowledge encrypted sharing between phones, laptops, and terminal agents without logins or clutter.

Instant 4-Char PIN & Vanity URLs

Drop anything and receive an easy 4-character code (e.g. #ABCD) with instant QR codes and direct links (/ABCD).

In-Browser Inspector & Lightbox

Inspect full-resolution photos with zoom/pan, preview syntax-highlighted code with line numbers, and stream media without downloading.

Zero-Knowledge Client E2EE

Military-grade AES-256-GCM encryption in your browser. Keys stay in URL fragments (#key=...) and never touch server storage.

WebRTC Direct LAN P2P Mode

Direct peer-to-peer device transfer bypassing the cloud for ultra-fast local network transfers up to 10 GB.

Folder Hierarchy & ZIP Bundler

Drag whole directories with subfolders intact. Receivers can browse hierarchy or grab everything with one-click ZIP download.

Native Android App & Share Sheet

Share directly from Android Gallery or Files apps, live camera QR viewfinder, and self-updating APK architecture.

Sender-Only Deletion & Auto-Expiry

Custom TTLs (5m to 24h) and burn-after-reading. Only the original sender has permission to delete or revoke drops.

AI Agent & Terminal MCP Tools

Automated Model Context Protocol (MCP) server and TypeScript SDK (atmr-drop-client) for agent workflows.
